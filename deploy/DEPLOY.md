# Публичный стенд HEATNET на VPS

Инструкция разворачивает сервис в интернете с HTTPS-адресом за ~10 минут.

## 1. Арендовать VPS

Подойдёт минимальный тариф любого хостинга: **Ubuntu 22.04, 2 ГБ ОЗУ,
1–2 vCPU, 20 ГБ диска** (Timeweb Cloud, Beget, reg.ru и т.п.). Записать
IP-адрес сервера — далее он обозначается `IP`.

## 2. Установить Docker (на сервере, один раз)

```bash
ssh root@IP
curl -fsSL https://get.docker.com | sh
```

## 3. Развернуть сервис

```bash
git clone https://github.com/dmitrywalther/heatnet.git
cd heatnet
DOMAIN=heatnet.IP-с-дефисами.nip.io docker compose \
    -f docker-compose.yml -f deploy/docker-compose.prod.yml up -d --build
```

`nip.io` — бесплатный сервис: имя `heatnet.1-2-3-4.nip.io` само
указывает на IP `1.2.3.4`, регистрировать ничего не нужно. Caddy при
первом запросе автоматически выпустит сертификат Let's Encrypt.

Первая сборка занимает 5–15 минут. Проверка:

- `https://heatnet.IP-с-дефисами.nip.io/ui/` — веб-интерфейс;
- `https://.../swagger-ui.html` — API.

## 4. Свой домен (по желанию)

Купить домен (~300 ₽/год), создать A-запись на `IP`, перезапустить
с `DOMAIN=ваш.домен` — сертификат выпустится автоматически.

## Заметки

- `JAVA_OPTS=-Xmx1400m` в prod-надстройке подгоняет JVM под 2 ГБ ОЗУ
  (базовый Dockerfile рассчитан на машину проверки из ТЗ с 16 ГБ).
- Порт 8080 наружу не нужен — весь трафик идёт через Caddy (80/443);
  при желании закройте его файрволом хостинга.
- Обновление стенда: `git pull` и та же команда `up -d --build`.
  **После стоп-кода хакатона стенд не обновлять.**
